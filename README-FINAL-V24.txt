PURPOSE
This is the complete replacement package for the public portfolio. It restores the full site stylesheet and consolidates the final HTML, JavaScript, SEO metadata, image references, sitemap and robots configuration into one deployable tree.

DEPLOYMENT
1. Extract the ZIP.
2. Upload the CONTENTS of the extracted folder to the root of the GitHub Pages repository/branch that currently serves ronald.saraswatintegratedservices.com.
3. Allow files with the same paths to be replaced, especially:
   /index.html
   /research/index.html
   /publications/index.html
   /experience/index.html
   /community/index.html
   /scientific-visuals/index.html
   /about/index.html
   /cv/index.html
   /contact/index.html
   /css/style.css
   /js/main.js
   /robots.txt
   /sitemap.xml
4. Keep the directory structure exactly as supplied.
5. Do NOT upload a CSS patch in place of /css/style.css. The supplied /css/style.css is the complete master stylesheet.
6. The package uses /css/style.css without query-string version numbers. If a browser shows an older style immediately after deployment, perform one hard refresh; no HTML version-number maintenance is required.
